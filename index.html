ABOUT STREAMHUB

Built for a GitHub Pages site.

StreamHub is a front-end launcher/player. It does not proxy, download, decrypt, or bypass any streaming service. Some platforms require their own player or block iframe embedding.

For Twitch embeds, the platform requires a valid parent domain. GitHub Pages sites are supported by using your actual Pages hostname.
